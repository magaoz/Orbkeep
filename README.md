# Orbkeep

Place keepers. Pop the orbs. Knowledge lasts forever.

## Play (permanent)

**https://magaoz.github.io/Orbkeep/**

On phone: open that link → Install app / Add to Home Screen. Progress saves on the device.

## Dev

```bash
npm install
npm run dev
npm run build
```

GitHub Pages deploys from the `gh-pages` branch (built `dist/` with base `/Orbkeep/`).
